# QuestPorts for Meta Quest — app releases

This repository only hosts release builds of the **QuestPorts** headset app.
The app opens the [QuestPorts catalog](https://questports.vercel.app) in a 2D panel
and installs standalone VR ports on your Quest with one tap — no PC, no Developer Mode.

## Download

Grab `QuestPorts.apk` from the [latest release](https://github.com/felipevc13/questports-app/releases/latest).

Install it from Quest Browser → Files → Package Installer. The first time you install
a game, allow QuestPorts to install unknown apps.

Once installed, the app checks this repository for new versions and offers to update itself.

> Installed an early test build? If an update fails with a signature error,
> uninstall QuestPorts once and install the latest release. This only happens one time.

Source code is private. Releases are published automatically by CI.
